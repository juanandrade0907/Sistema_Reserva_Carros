# 🚘 Sistema de Reserva de Carros — Banco de Dados SQL

📌 Sobre o Projeto
---

Este projeto foi desenvolvido como parte das atividades acadêmicas do curso de Ciência da Computação, com o objetivo de aplicar conceitos de modelagem e manipulação de bancos de dados relacionais utilizando SQL.

O trabalho consiste na criação, estruturação e documentação de um banco de dados relacional para o **Sistema de Reserva de Carros**, contemplando o controle de veículos, clientes, reservas e contratos de aluguel.

🛠️ Tecnologias Utilizadas
---

- **MySQL** — Sistema de gerenciamento de banco de dados relacional.
- **SQL** — Linguagem utilizada para definição (DDL), manipulação (DML) e consulta de dados (DQL).

📁 Estrutura de Arquivos
---

O projeto é composto pelos seguintes arquivos e diretórios:

- `ReservaCarros.sql` — Script SQL contendo a criação das tabelas, restrições e inserção de dados.
- `SQL Reserva Carros.pdf` — Documentação complementar contendo o diagrama E-R / modelo conceitual do sistema.

🎨 Conceitos Aplicados
---

Durante o desenvolvimento do projeto, foram trabalhados conceitos fundamentais de Banco de Dados:

- Criação e estruturação de tabelas (`CREATE TABLE`).
- Definição de chaves primárias (`PRIMARY KEY`) e chaves estrangeiras (`FOREIGN KEY`).
- Mapeamento de cardinalidades e integridade referencial.
- Inserção e atualização de registros (`INSERT` e `UPDATE`).
- Consultas, filtragens e ordenação de dados (`SELECT`, `WHERE` e `ORDER BY`).

🎯 Objetivo Acadêmico
---

Consolidar os conhecimentos em modelagem e manipulação de bancos de dados relacionais, desenvolvendo habilidades práticas na escrita de scripts SQL bem estruturados e na documentação de esquemas de dados.
